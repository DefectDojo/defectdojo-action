# Security

This action handles a DefectDojo API key and uploads scan reports. If you find a way to make it leak the key, send data anywhere other than the configured DefectDojo instance, or run code it shouldn't, please tell us.

Report it through DefectDojo's HackerOne [disclosure submission program](https://hackerone.com/defectdojo/reports/new). The process, embargo and safe harbor are the same as for DefectDojo itself: see [DefectDojo's security policy](https://github.com/DefectDojo/django-DefectDojo/blob/master/SECURITY.md).

Please do not open a public issue for a security problem.
